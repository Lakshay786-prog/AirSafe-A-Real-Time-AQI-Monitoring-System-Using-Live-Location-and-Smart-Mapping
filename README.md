🌍 AirSafe – Real-Time Air Quality Monitoring App

AirSafe is a web-based application that provides real-time Air Quality Index (AQI) information to help users make safer outdoor decisions. The app uses live GPS location and AQI APIs to display air pollution levels on an interactive map.

Users can view AQI for their current location or search for any city worldwide. The AQI is shown in a simple, color-coded format (Good, Moderate, Poor) along with detailed pollutant data such as PM2.5, PM10, NO₂, O₃, CO, and SO₂.

This project is designed to support health awareness, environmental monitoring, and smart city initiatives. It is especially useful for asthma patients, elderly people, daily commuters, and outdoor workers.

✨ Features

Live location AQI detection

City-based AQI search

Interactive map with AQI marker

Detailed pollutant information

Simple and user-friendly UI

🛠️ Technologies Used

HTML, CSS, JavaScript

Leaflet.js & OpenStreetMap

API-Ninjas Air Quality API
